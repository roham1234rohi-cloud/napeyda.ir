# محدودیت‌های باقی‌مانده
1. **مجوز تجاری Vercel**: پلن Hobby غیرتجاری است؛ برای فروش واقعی بررسی/ارتقا لازم است.
2. **ساخت و تست‌ها اجرا نشده‌اند** (جدول گزارش تست). احتمال خطای تایپ یا lint هست.
3. **Instagram API تست نشده**: OAuth و API فقط از روی مستندات نوشته شده؛ نیازمند Meta app، حساب Creator و KV است. در Development mode فقط حساب‌های دارای نقش مجازند. تصاویر CDN اینستاگرام منقضی می‌شوند و Reels با کاور نمایش داده می‌شوند.
4. **Rate limit** مسیر `/api/instagram/media` در حافظه هر instance است و در serverless محافظت کامل نیست. برای محافظت کامل از Vercel Firewall یا KV استفاده کنید.
5. **تحویل محصول دستی است**؛ لینک خصوصی با انقضا و کنترل دسترسی سمت سرور پیاده‌سازی نشده. لینک غیرقابل حدس به‌تنهایی امنیت واقعی نیست و با اشتراک‌گذاری قابل پخش است.
6. **فرم خرید** فقط پیام تلگرام می‌سازد؛ ثبت یا پیگیری سفارش، شناسه سفارش و جلوگیری از سوءاستفاده ندارد.
7. **لینک ۵۰ ابزار** بررسی زنده نشده‌اند؛ سایت آن‌ها را «بررسی نشده» نشان می‌دهد.
8. **ZIP محصول**: گالری ۱۰ مرجع متنی است، نه تصویر. ادعای «۱۰ تصویر» نباید اضافه شود.
9. **محتوا**: فقط ۳ مقاله و ۲ آموزش؛ موضوع‌های معرفی ابزارها، تولید تصویر و تولید ویدیو مقاله ندارند. برچسب‌ها صفحه جدا ندارند. لوگوی رسمی ابزارها نیست (آیکون حرف اول).
10. **طراحی**: لوگو سه‌بعدی با CSS است، نه Three.js. تصویر OG ندارد. بررسی چشمی و موبایل انجام نشده.
11. **قوانین**: متن‌ها پیش‌نویس‌اند، بازبینی حقوقی نشده‌اند؛ قوانین بازگشت وجه پیشنهاد من است و باید تأیید شود.
12. **CSP** از `unsafe-inline` برای اسکریپت استفاده می‌کند (الزام فعلی Next.js بدون nonce). `FAQPage` schema عمداً اضافه نشده است.
13. **Meta**: نام منوها و نیاز به App Review ممکن است عوض شده باشد؛ با مستندات روز تطبیق دهید.
