# بروزرسانی محتوا (بدون پنل مدیریت)
| چه چیزی | فایل |
|---|---|
| قیمت، شمارش‌ها، پوشه‌های محصول | `content/product.ts` |
| مقاله‌های وبلاگ | `content/posts.ts` (یک آیتم جدید با slug یکتا) |
| آموزش‌ها | `content/tutorials.ts` (نام ابزارها باید در `content/tools.json` باشد) |
| سؤالات متداول | `content/faq.ts` |
| صفحات قانونی | `content/legal.ts` |
| ابزارها | `content/tools.json` (از Excel داخل ZIP تولید شده) |
| تلگرام و اینستاگرام | متغیرهای محیطی |

## تغییر محتوای ZIP محصول
1. فایل جدید را در `private/` بگذارید.
2. `npm run check:zip` را اجرا کنید و شمارش‌ها را با `content/product.ts` تطبیق دهید.
3. هر ادعای سایت را با ZIP واقعی بسنجید؛ اگر چیزی در ZIP نیست، از سایت حذف کنید.
4. وقتی تصاویر واقعی (با مجوز) به بسته اضافه شد، متن گالری را در `product.ts`، `faq.ts` و `legal.ts` بروز کنید.
## بررسی لینک ابزارها
`npm run check:links` را با اینترنت اجرا کنید؛ فقط لینک‌های `ok` به‌صورت «بررسی‌شده» نمایش داده می‌شوند.
